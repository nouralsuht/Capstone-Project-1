# Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, Flexbox, and Bootstrap.

## Features

- Responsive design
- Modern portfolio layout
- Navigation bar
- Hero section
- Projects section
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Bootstrap
